# La Toile V28 — Experience UI

V28 starts from the validated V27 orchestration and turns the main interface into a globe-first traveler experience.

## UX flow

Globe → Country → Intent → Qualification → Territory → Matching → Professional responses → Comparison → Traveler decision → Vault → Journey

## Changes

- Interactive country points on the primary globe.
- Country selection remains dynamic and uses the same country template.
- Country selector and globe stay synchronized.
- Premium dark visual treatment.
- V27 API/orchestration remains untouched.
- V26/main remains untouched.

## Principle

The globe is the primary entry point. The interface organizes and explains; the traveler decides.
